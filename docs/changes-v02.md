Tarotoo 的78张牌包含逐牌正逆位资料和领域字段。来源是发布者整理的资料，不是预测效果数据集，也不为每一条牌义提供独立书籍页码。本包保留来源和固定commit，附MIT许可，不把yes_no字段作为现实结论。
