## 机器辅助抽查记录

实际对照附带英文、中文历史摘要和项目改写共19张牌，范围在 JSON 中列出；未声称其余59张中文语义已完成审核。

| 范围 | 观察与采用策略 |
| --- | --- |
| 愚者、魔术师、隐者 | 历史词表与现代常见“新开始／能力／智慧”不完全相同；保留负面和多义说明，日常只提供独立标记的反思改写。愚者逆位原文 `distribution` 未纳入中文摘述，因此只能称摘要。 |
| 皇后逆位 | 英文包含澄清与欢庆，也有摇摆；不替换为一律缺乏滋养。 |
| 命运之轮逆位 | 增加、丰裕、过剩；不自动套用坏运气。 |
| 权杖三、四逆位 | 分别为困境缓解、含义保持不变。Tarotoo偏向受阻／冲突的分支不进入新默认回答。 |
| 圣杯二逆位 | 主条目无单列逆位；来自 Part III §4 的补充。引用必须包含 `reversal_supplement`。 |
| 圣杯八、九逆位 | 圣杯八为喜悦幸福宴饮；圣杯九包含真诚忠诚自由及另一组错误不完美，不将愿望实现作为现实保证。 |
| 宝剑四、六逆位 | 前者谨慎管理等，后者声明坦白公开；不改写为通用“恢复忙碌／无法前进”。 |
| 星星 | 原典正位并列损失与希望两个分支。默认项目改写选择希望，问历史时必须呈现分歧。 |
| 死神、高塔、月亮、宝剑九、十 | 历史灾祸、疾病、死亡词不进入日常模型依据；只在明确历史研究时传入英文和中文摘要，不允许现实诊断或事件断言。 |
| 宝剑王后 | 历史婚姻、生育、性别和道德词不能用于判断现实人物。项目边界／表达建议单独标记。 |

具体发现与隔离：死神的原包中文象征描述“黑色玫瑰旗”可能误读成黑色玫瑰；英文对应黑旗上绘有 Mystic Rose（本地转录1790–1812行）。本轮不改原包、不凭图片补写颜色；适配器暂不注入该中文象征描述，并附 `review_note`，英文依据仍可展开。此限制随结果快照保存。

宝剑九 `miscarriage` 等历史措辞有语境歧义，未开展完整译词校勘；只保留为有选择的历史摘要，禁止用于医疗判断。其余保留摘要的删节说明，不虚标逐字翻译。
