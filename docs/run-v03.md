# 本轮启动、恢复与人工验收

## 启动

关闭旧版服务，保留`.env`、`data`和完整`Buxi_Tarot_Knowledge_v01`。在 `C:\Buxi` 执行：

```powershell
.\.venv\Scripts\python.exe scripts\local_preview.py
```

打开 http://127.0.0.1:8080 ，使用原内测码。前端已构建到`web/dist`。重新构建执行 `cd web`、`npm.cmd install`、`npm.cmd run typecheck`、`npm.cmd run build`，推荐Node22+。真实模型测试默认使用现有模型配置，不输出密钥。

## 备份与兼容迁移

首次新代码打开旧库，先用SQLite在线备份在同目录生成 `buxi.db.pre-v3-随机标识.bak`，然后新增会话、请求状态、删除墓碑表及dialogs列。未删除旧结果、账号、聊天或记忆。实际库只在运行时迁移，自动测试与模型评测均使用独立数据库。

迁移后的旧无关联聊天在对应角色日常会话中保留显示，但不猜测它的牌阵关系，也不默认加入后续上下文。未保存结果仍按旧24小时政策过期。

恢复：先停止所有卜犀进程，保留迁移后数据库和备份；把选定`.bak`复制到**新的恢复目录**，命名为`buxi.db`。不要覆盖唯一旧副本。使用保留的旧代码副本启动，并在当前PowerShell设置：

```powershell
$env:BUXI_DATA_DIR='C:\Buxi\data-restored'
# 从保留的旧代码目录，使用对应虚拟环境运行 scripts\local_preview.py
```

备份只包含迁移前时点；之后的新消息不在旧备份。若仍用新代码启动，会重新执行兼容迁移。不要仅复制正在使用的SQLite主文件而遗漏WAL。

## 人工验收清单（本轮尚未完成）

1. 原内测码登录 → 提问 → 三张牌 → 翻一张后刷新，核对同一ID、方向、牌位和翻牌进度。
2. 翻完 → 中文解读 → 展开细节与资料依据，核对版本、条目、历史摘要和项目改写标签。
3. “与绯月聊聊 · 携带当前结果” → 发送追问 → 刷新；同一会话和牌阵，无重复消息。切换独立日常聊天再返回原会话。
4. 开发者工具模拟断网或响应丢失，再重复原请求：不重抽、不重复消息，失败保留输入；解读失败只重试解读。
5. 仅用合成数据测试保存、修改、停用、删除记忆，确认后续回答不再获得旧记忆；旧消息仍可查看但退出上下文。
6. 删除合成结果，核对关联聊天清除，旧ID和旧请求不能恢复；独立记忆保留。用测试库调整时间验证24小时过期。
7. 第二账号、另一个角色验证隔离；跨角色分享仅携带结果；关闭问候后不再出现。
8. 桌面与手机尺寸检查卡背比例、卡外牌位、长消息、展开依据、减少动态效果。**真实手机**唤起键盘，检查输入与发送按钮可见；模拟视口不能替代这一步。

浏览器host不可用，本机Chrome回退因工具无法可靠识别当前URL被安全检查终止。因此本轮没有浏览器截图、桌面／移动视觉通过结论或真实手机键盘结论。

可运行 `scripts/ui_preview.py` 在8081启动隔离验收服务，合成数据位于`data/ui-acceptance`，演示码见脚本。仅用于本机测试，不能部署公开或指向真实库。自动化检查命令：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\knowledge_audit.py
```

`scripts/live_eval.py` 是显式真实模型评测入口，最多10次合成输入调用，存在服务调用成本；`--only`可定向复测。默认不在启动或自动单测中执行。
