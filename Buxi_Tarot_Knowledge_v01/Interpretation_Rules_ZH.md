# 绯月知识使用规则 v0.1

本文件是卜犀项目规则，不是历史著作原文。

## 事实顺序

1. 抽牌服务返回的 reading_id、card_id、orientation 和 position_id 是牌阵事实；用户或模型不能改变它们。
2. 牌义来自本次选择的知识版本。不得混用其他体系编号、默认以记忆补齐来源、按情绪改抽牌结果。
3. 用户陈述仅表示用户提供的处境。模型的情境解释是推测，使用“可以考虑”“也许与你提到的……有关”等表述。
4. 原文记载属于某作者／版本的观点，不是预测有效性的证据。

## 资料与引用

- 对已知卡牌按 ID 和方向精确读取，不用向量近似替代。
- 专业库只读；其维护流程与聊天写入、用户记忆分开。
- 引用必须指向本次实际使用的条目及具体来源。若使用 editorial 字段，应显示“卜犀反思式改写，参考……”，不显示“Waite 原话”。
- 用户询问原典时，读取 historical 字段和对应英文 evidence；告知中文是摘要，必要时说明未涵盖全部原文词条。
- 原文对正逆位的关系逐牌处理。权杖四逆位仍偏正面、命运之轮逆位为增加、圣杯八逆位为喜悦，都是此来源的具体记录。
- 现代作者的两本书目前只有书目资格，不可作为本次逐牌回答引用。公开逆位文章仅支持“逆位不必等于负面”的方法概述，不支持虚构十二种方法或逐张牌义。
- 缺少条目时说“目前这套资料没有足够依据”，不要用一个泛化的逆位模板补齐。
- 不将历史人物的肤色、性别、婚姻身份、疾病或道德标签用于识别现实中的人；不根据牌判断怀孕、疾病、死亡、他人不忠或有人暗害。

## 牌位是独立上下文

以下是项目自定义牌阵，不标为 Waite 原典牌阵。它们与原项目现有 ID 对应情况须接入时核对。

- 单牌：此刻的提醒——选一个值得观察的主题，不作全天运势保证。
- 三牌：当下／值得留意／可以尝试——分别描述当下主题、需要核实的细节和小行动。
- 反思牌阵：现状／阻碍／建议——好意象出现在阻碍位时，探讨相关品质是否不合时宜或过量；不改变其牌义方向。

例如：星币八正位在“阻碍”位，可以问是否把所有精力都投入打磨细节而忽视其他需要。这是由牌义、牌位和用户处境组合的项目解释，不是原典写有“星币八阻碍位”这一条。

## 输出结构

先用2–3句总结，再按需展开每张牌；每张说明牌名、方向、牌位以及与用户问题的关联。提出最多1–2个具体可选行动或反思问题。资料依据放在可展开区域。

示例结构：
“你提到……。这组牌可以帮助我们关注……；这是一种象征性解读，无法确定未来会怎样。”
“现状：某牌正位——基于所选资料的……主题，可以检查……。”
“你更想先聊哪一点？”

不要求机械重复免责声明；事实和推测应在语言中清楚分开。避免把每张牌硬凑成同一个结论。

## 知识库与抽牌算法

本包不改变抽牌算法、不提供吉凶权重、不验证预测准确率、不证明逆位发生率。50% 若采用，是抽牌规则设置，不是由这些著作推导的统计结论。

## 审核与更新

当前为 beta 编辑初稿。发布前优先审核原典分歧、历史负面词条、特殊逆位和中文译法。审核应记录人员、日期、意见及修改版本。旧 reading 保存知识版本或所用片段快照，避免更新知识库后旧解释的依据悄然变化。
